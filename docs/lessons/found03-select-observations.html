Lesson 3: Select Observations

How do we find the observations we’re interested in?

Learning Objectives

By the end of this lesson, you should be able to:

  • Recognize logical values (TRUE and FALSE).
  • Compare vector values using logical operators.
  • Explain what a logical vector represents.
  • Use logical indexing to select observations.
  • Connect a condition in R to a question about data.

Download the companion R guide for this lesson

Introduction

Suppose we want to answer a question such as:

Which states have populations greater than 10 million?

We already know how to retrieve an observation by its position:

states[9]
[1] "Florida"
populations[9]
[1] 21.929

But here we don’t know the positions ahead of time.

Instead, we need a way to ask R which observations satisfy a condition.

Comparisons return TRUE or FALSE

Let’s start with one observation.

Florida is the 9th state in our vectors.

populations[9] > 10
[1] TRUE

R returns TRUE because Florida’s population is greater than 10 million.

Now try a condition that is not true.

populations[9] < 5
[1] FALSE

R returns FALSE.

TRUE and FALSE are called logical values.

NoteKey Idea

A comparison asks a yes-or-no question.

R records the answer as TRUE or FALSE.

Some common comparison operators are:

Operator Meaning
> greater than
< less than
>= greater than or equal to
<= less than or equal to
== equal to
!= not equal to

Notice that R uses == to test whether two values are equal.

Compare an entire vector

The same comparison can be applied to every value in a vector.

populations > 10
 [1] FALSE FALSE FALSE FALSE  TRUE FALSE FALSE FALSE  TRUE  TRUE FALSE FALSE
[13]  TRUE FALSE FALSE

Instead of returning one answer, R returns one TRUE or FALSE for every state.

We can save those results as a new vector.

large_population <- populations > 10
large_population
 [1] FALSE FALSE FALSE FALSE  TRUE FALSE FALSE FALSE  TRUE  TRUE FALSE FALSE
[13]  TRUE FALSE FALSE

This is a logical vector.

Each value answers the same question for one observation:

Is this state’s population greater than 10 million?

TipPredict

What do you think this comparison will return?

regions == "S"
 [1]  TRUE FALSE FALSE  TRUE FALSE FALSE FALSE FALSE  TRUE  TRUE FALSE FALSE
[13] FALSE FALSE FALSE

How many TRUE values do you expect to see?

Logical vectors line up with the observations

The logical vector has the same number of values as the original data.

length(states)
[1] 15
length(large_population)
[1] 15

Each position still refers to the same observation.

For example, if the 9th value of large_population is TRUE, that tells us the 9th state satisfies the condition.

NoteKey Idea

A logical vector contains one TRUE or FALSE for each observation.

The positions still line up across all of our vectors.

Count observations that satisfy a condition

Sometimes we only want to know how many observations meet a condition.

In calculations, R treats TRUE like 1 and FALSE like 0.

That means we can use sum() to count the TRUE values.

sum(large_population)
[1] 4

We can also put the comparison directly inside sum().

sum(populations > 10)
[1] 4

For example, how many of the 15 states are in the South?

sum(regions == "S")
[1] 4

Select the observations that satisfy a condition

Often we want to know which observations meet the condition.

Previously, we used a number inside square brackets:

states[9]
[1] "Florida"

We can also put a logical vector inside the brackets.

states[large_population]
[1] "California" "Florida"    "Georgia"    "Illinois"

R keeps the state names wherever large_population is TRUE.

We can use the same logical vector with another variable:

populations[large_population]
[1] 39.243 21.929 10.823 12.693

Or we can write the condition directly inside the brackets.

states[populations > 10]
[1] "California" "Florida"    "Georgia"    "Illinois"
NoteKey Idea

Logical indexing keeps the values where the condition is TRUE.

This is the basic idea behind filtering observations.

Another Example

Suppose we want to find states with household income above $80,000.

The values in house_income are measured in thousands of dollars.

high_income <- house_income > 80
high_income
 [1] FALSE  TRUE FALSE FALSE  TRUE  TRUE  TRUE  TRUE FALSE FALSE  TRUE FALSE
[13]  TRUE FALSE FALSE

We can count the states that satisfy the condition:

sum(high_income)
[1] 7

and identify them:

states[high_income]
[1] "Alaska"      "California"  "Colorado"    "Connecticut" "Delaware"   
[6] "Hawaii"      "Illinois"   
house_income[high_income]
[1] 86.631 95.521 92.911 91.665 81.361 95.322 80.306

The process is the same each time:

  1. Write a condition.
  2. R creates a logical vector.
  3. Use that logical vector to count or select observations.

Optional Preview: Combining Conditions

Sometimes a question involves more than one condition.

The & operator means AND: both conditions must be true.

states[populations > 10 & populations < 30]
[1] "Florida"  "Georgia"  "Illinois"

The | operator means OR: at least one condition must be true.

states[regions == "W" | regions == "MW"]
[1] "Alaska"     "Arizona"    "California" "Colorado"   "Hawaii"    
[6] "Idaho"      "Illinois"   "Indiana"    "Iowa"

We’ll work more with combinations of conditions later. For now, the important idea is that each comparison still produces TRUE or FALSE.

Looking Ahead

So far, we’ve been selecting observations from individual vectors.

Soon we’ll work with data frames, where several related vectors are stored together. The same idea will carry over: filtering a dataset means keeping the observations that satisfy a condition.

Lesson Summary

By the end of this lesson, you should understand that:

  • Comparisons return logical values: TRUE or FALSE.
  • Comparing a vector creates a logical vector.
  • A logical vector contains one value for each observation.
  • sum() can count how many observations satisfy a condition.
  • Logical vectors can be used inside [] to select observations.
  • Filtering begins by identifying which observations satisfy a condition.
